# Library Management System

## Project Description
A JavaFX-based Library Management System developed for the ICD 121 assignment.

## Technologies Used
- Java
- JavaFX
- FXML
- Scene Builder
- Maven
- CSS

## Main Features
- Login and input validation
- Dashboard with library statistics
- Add and manage books
- Add, search, edit, and delete members
- Issue books to members
- Return borrowed books
- View borrowing history

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure JDK 21 and the required JavaFX dependencies are configured.
4. Reload the Maven project.
5. Run the application's main class.

## Data Storage
The current implementation uses in-memory data collections. Data may reset when the application is restarted.
